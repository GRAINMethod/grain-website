# grainmethod.com

The GRAIN Method website. Next.js 16 + Tailwind v4, deployed on Vercel from `main`.

```
npm install
npm run dev
```

- Brand, copy rules, structure and env vars: [AGENTS.md](AGENTS.md) (Cursor and Claude Code read it automatically)
- Prices and guarantees: `content/offer.ts`
- Leads: `/api/leads` saves to Supabase `public.leads`

Legal pages (privacy, terms, SMS terms) are plain-English drafts. Have an attorney review them before ads run.
